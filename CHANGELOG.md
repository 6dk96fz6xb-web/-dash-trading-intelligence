# Changelog

## v0.1.0 — 2026-09-16

- Added a dependency-free scoring engine.
- Added configurable liquidity and execution gates.
- Added `ENTER`, `WATCH`, `AVOID`, and `DATA INCOMPLETE` decisions.
- Added validated CSV input and JSON/terminal output.
- Added a read-only Streamlit dashboard.
- Added synthetic sample earnings candidates.
- Added unit tests and a GitHub Actions test workflow.
- Added the v0.1 data schema.

The scoring weights and thresholds remain provisional and have not been validated through out-of-sample backtesting.
